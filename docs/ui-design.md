# 工作台界面设计

> 实现后回填：本文用于说明现有界面的取舍，实际规则以 `frontend/src/styles.css` 与各页面组件为准，不作为实现前的规范。

面向用户咨询、客服处理、知识审核与知识入库四个任务。导航与页面按角色显示；使用真实订单与操作状态，页面不填充伪造的运营指标。

## 视觉规则

背景 #F4F7F8，工作区 #FFFFFF，导航 #123442，正文 #183340，操作色 #087E78，分隔线 #E7EDEF。绿色只表达当前操作、确认或完成；待审核使用暖黄色，驳回使用淡红色。

中文采用系统中文字体，标题、正文和时间标签区分字号与字重。主要操作保持单一主色，次要操作使用白底边框。订单与处理证据比装饰性图表占据更多空间。

## 布局

客服咨询桌面布局：导航、最近会话、对话工作区、当前用户订单。移动端将会话切换置顶、订单放在对话之后，保留全部业务入口。

售后工作台：申请队列、订单与申请详情、处理时间线、审核意见。版本冲突提示刷新，失败时保留用户填写的意见。

知识运营：问题队列、真实来源、可编辑审核答案。索引失败明确显示失败，发布成功只在后端完成索引后显示。

知识库：顶部四个数字（知识块、待向量化、Milvus 条数、双写一致性），材料清单与最近入库并列；录入与切块预览左右分栏；检索自测把命中证据按分数排序；挖掘暂存区逐条采纳或弃用。任何一个计数对不上都要能直接看出来。

确认弹窗采用 Radix Dialog 管理焦点、键盘关闭与无障碍标题；图标使用 Lucide；样式在 frontend/src/styles.css 中统一维护。
